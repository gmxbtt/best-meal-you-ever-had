One sentence, at most 200 characters, about the best meal the agent ever
had: warm roti bakar with condensed milk at grandmother's kitchen table in
Bandung, rain hammering the tin roof, sugar on the chin, and her laughing.

## Run it

```sh
python3 main.py
```

The program prints exactly that one sentence — no title, no explanation,
no list of courses — and nothing else.
